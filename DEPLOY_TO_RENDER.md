## 📊 What Each Variable Does

### DATABASE_URL
```
postgresql://postgres.xxxxx:password@aws-0-xx-xx-xx.pooler.supabase.com:5432/postgres
```
**Role**: Connects to your Supabase PostgreSQL database  
**Stores**: Users, shipments, documents, alerts, costs, everything  
**Without it**: ❌ App crashes immediately

---

### TRIGGER_API_KEY
```
tr_pat_your_actual_key
```
**Role**: Authenticates with Trigger.dev cloud automations  
**Triggers**: 22 automated workflows (document processing, compliance, alerts)  
**Without it**: ⚠️ Uploads save but NO automations run

---

### GEMINI_API_KEY
```
AIzaSy...your_google_ai_key
```
**Role**: Access to Google Gemini AI engine  
**Powers**: Document classification, data extraction, executive summaries  
**Without it**: ⚠️ AI features fail, basic processing works

---

### GEMINI_MODEL
```
gemini-1.5-flash
```
**Role**: Specifies which Gemini model to use  
**Why flash**: Fast, cost-effective, great for document processing  
**Alternative**: `gemini-1.5-pro` (slower, more accurate, costs more)

---

### JWT_SECRET
```
(auto-generated by Render)
```
**Role**: Signs authentication tokens  
**Security**: Users can't forge tokens without this  
**Without it**: ❌ Login/authentication broken

---

### NODE_ENV
```
production
```
**Role**: Tells app it's running in production  
**Effects**: 
- Disables detailed errors (security)
- Enables caching
- Optimizes performance

---

### API_PORT
```
10000
```
**Role**: Port server listens on  
**Why 10000**: Render free tier requirement  
**Without it**: ❌ Server won't receive requests

---

### UPLOAD_DIR
```
/tmp/uploads
```
**Role**: Where uploaded documents are stored temporarily  
**Why /tmp**: Render's writable directory  
**Flow**: Upload → save here → Trigger.dev processes → data extracted

## 🚨 Common Issues & Fixes

### Issue: Build fails with "Cannot find module"
**Fix**: Check `package.json` has all dependencies
```bash
npm install @google/generative-ai bcryptjs express jsonwebtoken
```

### Issue: "DATABASE_URL is not defined"
**Fix**: Add it in Render dashboard → Environment variables

### Issue: Health check fails
**Fix**: 
1. Check logs in Render dashboard
2. Verify DATABASE_URL is correct
3. Make sure Supabase project is active

### Issue: AI extraction fails
**Fix**:
1. Verify GEMINI_API_KEY is correct
2. Check Render logs for "Gemini API error"
3. Test key at https://aistudio.google.com

### Issue: Automations don't trigger
**Fix**:
1. Verify TRIGGER_API_KEY is correct
2. Check Trigger.dev dashboard for task runs
3. Verify TRIGGER_PROJECT_ID matches
